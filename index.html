Hakkımda

İlişkisel veri tabanı mimarisi, veri bütünlüğü (ACID), yüksek eşzamanlılık kontrolü ve analitik veri ambarı (ETL) sistemleri üzerine odaklanan Yönetim Bilişim Sistemleri lisans öğrencisi. PostgreSQL, PL/pgSQL ve Python teknolojileriyle güvenli ve ölçeklenebilir arka uç (backend) çözümleri geliştirmektedir.

Projeler

LedgerFlow — Çift Taraflı Cüzdan ve Para Transfer Motoru

GitHub Repo ↗

PostgreSQL • PL/pgSQL • Python (Flask) • Concurrency Control • JSONB

  • Çift taraflı muhasebe (double-entry bookkeeping) mimarisine dayalı ilişkisel veri tabanı şeması tasarlayarak finansal tutarlılığı CHECK (balance >= 0), UNIQUE ve ON DELETE RESTRICT kısıtlamalarıyla veri tabanı katmanında garanti altına aldı.
  • Eşzamanlı para transferlerinde yarış durumlarını (race condition) ve kilitlenmeleri (deadlock) önlemek amacıyla SELECT ... FOR UPDATE satır kilitleme ve artan ID sırasıyla kilitleme algoritması geliştirdi.
  • Cüzdan bakiyelerindeki tüm değişimleri eski ve yeni değerleriyle birlikte değiştirilemez JSONB formatında kaydeden otomatik PL/pgSQL denetim tetikleyicileri ve çok iş parçacıklı (multi-threaded) stres testleri kurguladı.

MetricFlow — Otomatik ETL Veri Ambarı ve Analitik API

GitHub Repo ↗

PostgreSQL • Star Schema • Python (Pandas, Flask) • COPY Protocol • Materialized Views

  • Analitik raporlama sorgularını optimize etmek amacıyla merkezi satış olgu tablosu (fact_sales) ile tarih, müşteri ve ürün boyut tablolarından (dimensions) oluşan Yıldız Şema (Star Schema) veri ambarı tasarladı.
  • Python Pandas ile 10.000+ satırlık ham veri akışındaki mükerrer ve hatalı kayıtları filtreleyerek PostgreSQL COPY FROM STDIN protokolüyle yüksek hızlı toplu veri aktarımı (ETL) ve süreç loglaması geliştirdi.
  • Aylık kategori kârlılıklarını Materialized View üzerinde önbellekleyip müşteri segment sıralamalarını Window Functions (RANK, PARTITION BY) ile hesaplayan REST API uç noktaları oluşturdu.
